# Werewolf Agent 01

Heuristic Bayesian Werewolf agent for make.fun werewolf-agent-01 competition.

Plays 30 games per trial (15 as werewolf, 15 as village: seer/doctor/villager) via MAKEFUN_ENV_URL. Standard library only, deterministic given observe views.

## Run
python3 main.py

See makefun/kit for harness/grader.
